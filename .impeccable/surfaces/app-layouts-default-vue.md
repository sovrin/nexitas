# Surface: the nexitas app (shell, page kit, every module's pages)

Mode: Operate. The owner checks the suite between other work, laptop and phone, tabs left open.
Scope: the core's shell and page kit, and through them every module's pages. aequitas only.

## Direction contract

THESIS: A dark-first working console: panes that hold their place, divided by hairline seams, where the list stays put while the selected item opens beside it. It refuses the category's top-bar-plus-centred-page and its card grid.

OWN-WORLD: aequitas dark (night glass ground, sunken wells, moon ink), compact density, square corners, hairline seams instead of shadows between panes; small-caps pane headings; tabular mono figures; one accent hue per module (censitas teal, collatas orange, erratas pink, veritas indigo, linguitas green), the core graphite; state as square dots beside words; glass only where it floats (menus, dialogs, ⌘K).

STORY: The owner sees every module of the open project with its live figure in the sidebar, opens the one that moved, works its list with the selected item in the inspector, and acts in a few keystrokes; ⌘K reaches any project, module or page.

FIRST VIEWPORT: Sidebar (project switcher, MODULES with hue mark + label + figure, INSTALL, ⌘K, footer: theme, version, sign out); main pane: header line (trail / title, state meta, actions), filter row, dense table; inspector pane on the right (properties, body, primary action in the module hue, destructive action alone at its foot).

FORM: Dark Developer Console, the dealt challenger chosen over the assigned direction; seed key 1c660a10.
